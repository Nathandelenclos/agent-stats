Local usage reports for AI coding agents

See what Claude Code, Codex, and other coding agents used, what it cost, and which sessions drove it. agent-stats reads the logs already on your machine.

Install agent-stats Open the local dashboard

What you can inspect

Usage
Compare requests, tokens, cache use, and estimated cost by coding agent, model, or folder.
Sessions
Open a session to see its models, tools, subagents, and prompt signals.
Prompts
Find requests you keep repeating and see where flagged prompts cluster.

Your logs stay local

agent-stats reads your logs and writes an index on your machine. This website shows sample data and runs independently of the local dashboard.
